# Media Labeler

buat misahin poto, video atau apapun itu ke folder folder tertentu

cuma bisa buat dari lokal ke lokal sama dari drive ke lokal gabisa dari drive ke drive. 

### Cara Pakai:
1. Install dulu bahan-bahannya: `pip install -r requirements.txt`
2. Jalanin: `python labeler_app.py`
3. Pilih folder asal sama folder2 jenis
4. Klik tombol kategorinya buat mindahin file
